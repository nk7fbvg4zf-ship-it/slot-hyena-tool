# Professional Ver.9.0

設定判別を全52機種専用化。

- 52/52機種に専用の朝イチカウンター項目
- AT/CZ/BIG/REG/直撃/小役契機/引き戻し/モード選択/ゾーン系を、設定差が確認できるものだけ機種別に表示
- 成功率系は「成功回数 / 判定母数」をセットでカウント
- 東京喰種: 液晶Gと実G/台内履歴を分離
- SAO2: ボタン/メニューの台内履歴を優先
- ヨルムンガンド: 小役出現数ではなくレア役→CZをカウント
- 炎炎2: 炎炎ループ、伝導者の罠小V抽選、各種確定示唆
- からくり2: 強チェリー→CZ/AT、運命盤→AT直撃
- レールガン2: 通常CZと婚后上位CZを分離
- ジャグラー: BIG/REG/ブドウの朝イチカウンター
- 公開数値が揃った機種は設定一致度へ接続
- 未接続項目はカウンターとして使えても一致度には勝手に加算しない
- 確定/濃厚示唆は設定下限として反映
- localStorageで台ごとに継続保存
