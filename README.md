# Professional Ver.6.3

今回の追加
- 各機種ページでG数を入力すると、その場で推定投資額を自動表示
- 天井までの残りGを自動表示
- 推定必要時間を自動表示
- 保存済み閉店時刻から「時間余裕あり / 注意 / 見送り」を自動表示
- 推奨開始期限を自動表示
- 数値EVが取得できる場合は期待時給も自動表示
- 東京喰種 / かぐや様 / モンキーV は複数天井やリセット条件を個別処理
- その他の機種は収録済み天井表記から自動計算

重要
- 機種別の正確な千円ベースをまだ確認していない台は、32G/千円の暫定基準で「概算」と明記します。
- 機種別ベース値を確認できた台から自動で置換できる構造です。
